GOPI PORTFOLIO — EDITABLE PORTRAIT

Files:
- index.html: portfolio website
- assets/profile-portrait.jpg: generic generated male placeholder portrait

To replace the portrait later in VS Code:
1. Open this project folder in VS Code.
2. Replace assets/profile-portrait.jpg with your own photo, keeping the same filename.
3. Save the file and refresh the browser.
   (If you use a different filename, update the img src in index.html.)

The placeholder is not a photo of you.
Your GitHub, LinkedIn, email and CV links can be configured in the CONFIG object
near the bottom of index.html.
